Drafting outward — read before any client-facing draft


## Register at the boundary
- Plain language at the boundary; jargon stays interior. Name the audience before choosing the register, every time.
- For anyone outside the day-to-day work (client contact, account manager, practice administrator), the agent-natural register — comprehensive, contextual, project-aware — overwhelms. Lead with the action ("review and approve these 6 settings"), not the context. 1–2 sentences per item. Prefer .docx with response fields over raw markdown. Chunk so the hard decisions aren't bundled with the bulk ones. Structure it so silence isn't a valid default.
- Open human, close specific. One warmth line in; one concrete ask per named person out.

## Errors, evidence, predictions
- Own errors in one clause, then move. No apology spirals, no groveling: the correction is the apology.
- Evidence rides inline: the log line, the number, the screenshot reference. A claim without its artifact is a draft, not a send.
- Where the diagnosis supports it, stake the prediction in writing: "if X was the cause, Y will show Z on the next run." A prediction is a promissory verification; it makes the next email honest.
- State process motives openly (why we're collecting this, what the record is for). No hidden bookkeeping.
